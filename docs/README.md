# Documentation

Project-level documentation covering architecture, pipeline design, data lineage,
and architectural decision records.

## Contents

| File | Description |
|------|-------------|
| `architecture.md` | System architecture overview, data flow, Docker service topology |
| `pipeline.md` | Airflow DAG details, task graph, environment variables, error handling |
| `lineage.md` | End-to-end and column-level data lineage diagrams |
| `decisions/adr_001_architecture.md` | ADR for technology stack choices |

## Conventions

- All documentation is written in English.
- Mermaid diagrams are used for visual representations.
- ADRs follow the format: `adr_NNN_<topic>.md`.
